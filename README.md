# Electricista Senatino — Landing Page

## Estructura del proyecto
```
index.html          → estructura de la página
css/styles.css       → todos los estilos
js/main.js           → menú móvil (abrir/cerrar)
assets/img/          → coloca aquí las fotos reales
```

## Cómo agregar tus fotos
Busca los bloques marcados con la clase `imgph` (image placeholder) en `index.html`.
Reemplaza ese `<div class="imgph">...</div>` por:
```html
<img src="assets/img/nombre-de-tu-foto.jpg" alt="Descripción de la foto">
```
Guarda la foto dentro de `assets/img/` con ese mismo nombre.

## Cómo verlo
Abre `index.html` en el navegador, o usa la extensión "Live Server" de VS Code
para ver los cambios en tiempo real mientras editas.
